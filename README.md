# 🧠 AI Sprint Manager

**AI Sprint Manager** é um sistema de gerenciamento de projetos baseado na metodologia Ágil, com suporte inteligente por IA. Ele identifica o perfil técnico de cada membro da equipe e distribui automaticamente as tarefas de forma estratégica, otimizando tempo, entregas e performance.

---

## 🚀 Funcionalidades Principais

- Cadastro de perfis personalizados dos membros da equipe
- Criação de projetos com escopo descritivo
- Planejamento automatizado via Inteligência Artificial
- Distribuição de tarefas baseada em competências individuais
- Painel Kanban para visualização de progresso
- Alertas diários de tarefas por e-mail e integrações
- Aprendizado contínuo com base no histórico da equipe

---

- [OpenAI API](https://platform.openai.com/)
